# Protected paths: the land rule (docs/agents/intake.md). This file is itself t1-hard.
# A line is `<tier> <pattern>`. A pattern ending in `/` is a directory prefix, `*/<name>` matches
# that file or directory name anywhere, anything else is one exact path. The most severe tier
# that matches wins: t1-hard, then t1-origin, then t2.
#
# t1-hard: every landing needs `devhub intake approve` at the user's terminal (what needs the
#   user's eye even from our own lanes).
# t1-origin: a lane made from an intake item needs that approval; any other lane lands and the
#   landing is recorded for the daily push review.
# t2: a lane made from an intake item needs an adversarial-review record; any other lane lands
#   and the landing is recorded.
# The root Cargo.toml is ruled per hunk in protect.rs: [patch] and any non-path dependency are
# t1-hard (a new external dependency needs the user), the rest is t1-origin.
# t2 never matches a test or fixture path (a `tests`, `fixture`, `fixtures` or `testdata`
# directory): the record lists only real build scripts and macro crates.

# t1-hard: CI, what every build reads, and the intake code with this list
