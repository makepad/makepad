Inputs for tools/dbus_codegen (AT-SPI2 glue). The .xml files are not committed: regenerate them on a
Linux node with at-spi2-core installed. They are the D-Bus introspection data that the installed
accessibility bridge library carries (one string per interface), extracted from that file:

  ssh arch@<node> 'python3 - /usr/lib/libatk-bridge-2.0.so' < tools/dbus_codegen/extract_atspi.py > all.txt
  (then split at the '@@@ <interface>' lines; each file is <node><interface ...>...</interface></node>)
