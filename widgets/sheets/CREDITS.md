The sheets name these fonts from `resources/`. Each ships unmodified next to
its licence file.

- Anton, by the Anton Project Authors. SIL Open Font License 1.1
  (`resources/Anton-OFL.txt`). https://github.com/googlefonts/AntonFont
- Caveat, by the Caveat Project Authors. SIL Open Font License 1.1
  (`resources/Caveat-OFL.txt`). https://github.com/googlefonts/caveat
- Cormorant Garamond, by the Cormorant Project Authors. SIL Open Font License
  1.1 (`resources/CormorantGaramond-OFL.txt`).
  https://github.com/CatharsisFonts/Cormorant
- Fredoka, by the Fredoka Project Authors. SIL Open Font License 1.1
  (`resources/Fredoka-OFL.txt`). https://github.com/hafontia/Fredoka-One
- Lexend Zetta, by the Lexend Project Authors (Reserved Font Name
  "RevReading Lexend"). SIL Open Font License 1.1
  (`resources/LexendZetta-OFL.txt`). https://github.com/googlefonts/lexend
- Permanent Marker, by Font Diner. Apache License 2.0
  (`resources/PermanentMarker-LICENSE.txt`).
- Playfair Display and Playfair Display Italic, by the Playfair Display
  Project Authors (Reserved Font Name "Playfair Display"). SIL Open Font
  License 1.1 (`resources/PlayfairDisplay-OFL.txt`).
  https://github.com/clauseggers/Playfair-Display

(Inter, Roboto Flex, IBM Plex Sans).
